# ExamSarthi

## 📚 Overview

ExamSarthi is a web-based examination preparation platform designed to help students practice competitive exams through a structured and interactive environment. The system provides exam simulations, performance tracking, result analysis, and personalized user dashboards.

The platform supports multiple examinations such as:

* JEE
* NEET
* MHT-CET
* NDA

ExamSarthi aims to deliver a simple, responsive, and user-friendly experience while enabling students to evaluate their preparation through mock tests and detailed analytics.
